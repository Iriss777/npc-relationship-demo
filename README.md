# NPC 好感度 Demo

一个三日限定的生活模拟 NPC 关系系统设计 Demo，用于系统策划个人作品展示。

玩家需要观察 Emma 与 Leo 在不同时段的生活规律，通过探索、对话和送礼，在三个游戏日内逐渐建立关系。核心设计重点是 NPC 日程、关系成长、信息解锁和有限时间内的选择。

## 核心内容

- 五个可探索地点与按日变化的 NPC 日程
- 上午、下午、傍晚、夜晚四阶段时间系统
- 数据驱动的对话选择、礼物偏好与好感反馈
- 陌生、熟悉、朋友、亲密四级关系
- 双 NPC 关系事件与三日结算

## 本地运行

项目为纯静态网页。请在项目根目录启动任意静态 HTTP Server，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。
